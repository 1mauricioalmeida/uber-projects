# Passenger Experience

## Objetivo

Criar uma experiência web premium e acolhedora para passageiros, acessível por QR Code e otimizada para celular.

## Escopo inicial

O passageiro poderá, opcionalmente e sem identificação pessoal:

- receber uma mensagem de boas-vindas;
- escolher o conforto térmico;
- escolher o ambiente sonoro;
- indicar preferência por conversa ou silêncio;
- avisar se precisa de ajuda;
- enviar uma observação curta;
- avaliar atendimento, conforto e condições do veículo;
- deixar uma sugestão anônima;
- acessar um contato profissional futuro quando apropriado.

## Idiomas

- Português brasileiro.
- Inglês.
- Chinês simplificado.

## Requisitos de UX

- Mobile-first.
- Poucos toques.
- Sem login para o passageiro.
- Aparência premium e discreta.
- Botões grandes e legíveis.
- Feedback imediato após cada envio.
- Não depender de abertura de arquivo HTML local; deve operar como aplicação publicada via HTTPS.
