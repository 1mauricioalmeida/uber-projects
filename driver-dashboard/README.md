# Driver Dashboard

## Objetivo

Centralizar a operação do motorista sem expor informações aos passageiros.

## Escopo planejado

- visualizar preferências recebidas;
- destacar solicitações prioritárias;
- marcar solicitações como atendidas;
- acompanhar avaliações e sugestões;
- configurar mensagens, opções musicais e contato profissional;
- exibir o QR Code público da experiência do passageiro.

## Segurança operacional

O painel não deve exigir interação constante durante a condução. Notificações e controles futuros devem ser desenhados para minimizar distração e permitir atendimento quando for seguro.
